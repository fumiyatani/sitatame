# web/

Kotlin Web UI scaffold — Phase 0 PoC.

This directory exists to answer a single gating question:

> Can Kotlin's `snakeyaml-engine` produce a **bit-exact** round trip of the
> review YAML format that the Go side (`internal/review/codec.go`) emits,
> including unknown keys, YAML comments, and array order?

If the answer is yes, the Web UI route (B route) is viable. If it is no, the
schema-drift contract that protects existing CLI / TUI / agent integrations
cannot be guaranteed from a Kotlin renderer and the route is killed.

## Layout

```
web/
├── build.gradle.kts        # Kotlin 2.1 JVM + snakeyaml-engine 2.9 + JUnit 5
├── settings.gradle.kts
├── gradle.properties
├── gradle/wrapper/         # Gradle 8.11.1 wrapper jar + properties
├── gradlew, gradlew.bat
├── fixtures/               # Generated by `make web-fixtures`. DO NOT edit by hand.
└── src/
    ├── main/kotlin/dev/sitatame/web/roundtrip/
    │   ├── Codec.kt        # Compose -> Node tree -> Emitter (no struct mapping)
    │   └── Bytes.kt        # Byte-diff helper for the assertion failure message
    └── test/kotlin/dev/sitatame/web/roundtrip/
        └── RoundtripTest.kt
```

The Go fixture generator lives at `../cmd/yamlfixture/main.go`. It feeds
hand-written inputs through `review.Decode` + `review.Encode` and writes the
encoder output here. The fixtures are committed so a drift in either side
fails CI.

## Running locally

From the repository root:

```sh
make web-fixtures              # regenerate fixtures
cd web && ./gradlew test       # run the bit-exact round-trip test
```

Requirements: JDK 21 (CI uses Temurin 21, and `build.gradle.kts` pins
`jvmToolchain(21)` to keep local dev aligned with CI). The Gradle wrapper
downloads Gradle 8.11.1 and the dependencies on first run; network access to
`services.gradle.org` and Maven Central is required for the first invocation.

## Kill criteria

If `./gradlew test` reports any failure on the following fixtures, the Web UI
route is killed:

| Fixture | What it tests |
| --- | --- |
| `minimal.yaml` | Baseline: known fields + 1 comment round-trip cleanly |
| `unknown-top.yaml` | Top-level unknown key (`experimental_metadata`) survives |
| `unknown-comment.yaml` | Comment-level unknown keys survive |
| `with-yaml-comments.yaml` | YAML `#` comments survive |
| `array-order.yaml` | `comments[]` order is preserved |

When the gate fails, capture the diff from `Bytes.diff` and record the result
in `tmp/spec-web-ui.md` so the architecture decision is traceable.
